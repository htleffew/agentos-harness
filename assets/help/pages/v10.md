# Features

Features switches each part of the extension on or off, for the open chat or as the default for chats that use the selected preset. It also holds the Roast commentator voice, the planning and prose prompts and the Impersonate prompts.

Open it when a feature should stop or start for one chat, when a preset needs a new default, or to change how the Roast reads or how Impersonate is worded.

## What it does

### Quick action bar

**Open Quick actions, Bar** and **Open Quick actions, Library** lead to [Quick actions, Bar](page:quick-bar) and [Quick actions, Library](page:quick-library), where the bar above the message box and the saved quick actions are set.

### Features

The list shows while a chat is open and Roleplay Instructions is on. Two buttons choose what the switches change:

- **This chat** (the start) saves each switch with the chat. A chat's own setting wins over the preset default.
- **Extension defaults for this preset** saves each switch as the default for every chat that uses the selected preset. It is greyed out with no preset selected.

Each feature row has On and Off, a status line such as "On in this chat", and one line on what it does. A changed row gets a reset button such as **Use extension default for this preset (On)**. **Refresh source status** reads the preset again.

Every feature starts On except Roast generation and Roast feedback in future prompts. Terms such as Roast and Plot offer are in [Words this guide uses](help:glossary).

**Writing & reply display**

- Live writing guidance sends your writing guidance with each reply.
- Continuity guidance adds scene, knowledge, cast, pacing and continuity checks to the same reply.
- Dialogue colors colors dialogue and italic thoughts once the prose names the speaker.
- Roast generation (Off) asks for one Roast, a reader's comment on the reply, inside the same reply.
- Roast feedback in future prompts (Off) sends recent Roast comments with later replies as writing feedback.

**Story state & character continuity**

- Story, scene and character state tracks the scene, the story clock, character state and lasting facts.
- Character knowledge tracks what each character saw, heard or believes.
- NPC emotion scales tracks emotion scales and outward behavior.
- Relationships keeps short notes on each relationship and what changed it.

**Plot & mechanics**

- Arcs, seeds and off-screen agendas tracks open threads, planted details, payoffs and agendas.
- Plot offers rolls a chance each reply to offer an optional development.
- Dice spots an uncertain attempt before each reply, rolls it and sends one verdict. Stats are on [Story, Stats](page:stat-sheets).

### Instruction source & diagnostics

Each feature row can open this fold. It shows who supplies the feature now, read from the stack (the blocks sent in order) on [Setup, Presets](page:presets); a status line; and the preset blocks that do the same job, each On, Off or Status unavailable, with its text. When a matching preset block is on, the row reads "Preset block on · Extension off", its switch locks, and the extension sends nothing for that feature until the block is off in SillyTavern's Prompt Manager. The fold opens by itself on a locked row.

With the Roleplay Instructions V10 companion preset selected, **Request a reply plan** (Off) also appears; with any other preset a note names the preset to select.

### Roast commentator voice and feedback

- **Commentator voice** picks the voice for future Roast cards in every chat. Each voice keeps its own edits, and the editor under it is that voice's Roast voice prompt.
- **New commentator voice** takes a **Voice name** and a **Voice direction**; **Save new voice** creates and selects it.
- **Import or export a voice** reads a voice file or downloads the selected one.
- Writing the Roast and Using previous Roast commentary are the two prompts that follow.

Each prompt editor has:

- a text box holding the current wording
- **Variation**, your saved wordings, with Update, Save as, Rename and Delete
- **Restore default prompt**, which puts the shipped wording back, and **Undo restore**
- Import and Export, which read and write one wording as a file
- **Compare with default**, which shows the shipped wording beside yours
- **Discard draft**, which drops unsaved typing

An edit changes the one stored prompt, so [Setup, Prompts](page:prompts) shows it at once.

### Advanced prompts

When SillyTavern shows the preset's blocks, a card links to Setup, Presets. **Customize planning and prose prompts** holds Optional reply outline and Prose first.

The **Impersonation prompt** fold shows the base Impersonate uses now, a preview with this chat's macros, and the directions for the action.

- **Base for direct Impersonate** is Follow preset (the start) or Use extension instruction, kept per preset and connection.
- **Edit shared preset** (followed by the preset's name) appears when the preset's impersonation field can be written. **Shared impersonation instruction** is that field, and **Save shared impersonation prompt** saves it in the preset for every chat that uses it. Further buttons restore the original preset file or the wording from before the extension's edits, undo that restore, or load SillyTavern's own default into the draft.
- **Named variations** keeps saved wordings of the shared field. Pick one under Saved variation to compare, load, apply, rename, duplicate, remove or export it. **Import variation** reads a file, and **Undo removal** lists removed variations, each with Recover.
- Three Impersonate prompts follow: the one for Write my next message, the one for Give me choices (it keeps its {count} placeholder) and the one that turns a chosen option into your message.

The page ends with the version line, which says whether this SillyTavern has everything the extension needs.

## Model calls and cost

Nothing on this page calls a model; the switches decide what later replies carry ([how model calls work](help:model-calls)).

- Live writing guidance, Continuity guidance, Roast generation, Roast feedback and a requested reply plan ride SillyTavern's reply request.
- Dialogue colors and the Plot offers chance roll run in code; an offer that fires rides SillyTavern's reply request.
- Dice adds 1 model call before each reply, a judgment call on the routes in [Setup, Background jobs](page:background-jobs).
- The story state, knowledge, emotion, relationship and plot features are filed after each reply by a background call on the same page's routes. A paid route's calls count toward the monthly ceiling in [Setup, Spend](page:spend).
- The Impersonate prompts serve Write my next message, Give me choices and Draft from this choice, whose connections are set in [Setup, Connections](page:settings).

## Why it works this way

- A chat can differ from its preset without changing the preset, and a chat's own setting always wins.
- The extension steps aside for a feature whose preset block is on, so a reply never carries two sets of the same instructions.
- Roast starts off because it adds text to every reply.
- Every prompt is stored once, so the editor here and the one in Setup, Prompts show the same text.
