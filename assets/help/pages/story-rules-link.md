# Story rules

The Story rules entry under Story, Characters points to where story rules are set, [Direction, Story rules](page:story-rules). Many rules act on character values (emotions, relationships and faculties), so the link sits with the characters.

## What it does

The page has one line and one button, **Open Direction, Random sets**, which opens the Story rules page there.

A story rule is one sentence built from pickers. When a value on a reply card, a pending thread or the reply count meets a condition, the next reply carries a private [Direction](help:glossary) or lets a random event item roll. Each picker is described on the [Story rules](page:story-rules) page of this guide.

## Model calls and cost

Nothing on this page makes a model call. Story rules [run in code](help:model-calls) too; no rule asks a model anything.

## Why it works this way

Each setting has one home, and other places link to it. Story rules sit beside the random sets they draw event items from, and this link reaches them from the characters whose values the rules read.
