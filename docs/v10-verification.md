# Roleplay Instructions v10 verification

Baseline `6d21130` (10.0.22) on `roleplay-instructions-v10`, updated for 10.0.23. This audit compares the 24 decisions in the [running decision log](v10-vexa-decision-log.md) and the later requests in the conversation with the extension, the shipped companion preset, and the test assertions. A feature can exist in the code while still depending on host support or model behavior in use.

## SillyTavern verification

The test host is SillyTavern in Chromium with a synthetic Chat Completion endpoint. The tests drive the extension controls, inspect assembled requests, and check persisted chat and lorebook state. The full navigation audit visits all 22 extension pages and 153 reachable disclosures at both 390 and 1280 pixels, including the host and extension module settings. An independent first-time walkthrough reviewed Context & Memory, Writing Guidance, and lorebook navigation. It led to direct links to Story World and the book inventory, and clarified which system provides each check.

The baseline audit uploaded the two supplied guideline JSON files and compared the entries against the originals. The 12-entry book retained all twelve chances at 3%. The 10-entry book retained nine chances at 3% and one at 10%.
