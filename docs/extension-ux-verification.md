## Fixtures and coverage

Phone-width tests ran in Chromium against SillyTavern 1.19.0 at `7e8663cd9c184a550b37238218bdd32c6efc68e9`. Each run used one active preset. Default belongs to SillyTavern and Roleplay Instructions V10 is the extension’s companion preset. The navigation suites used a 390 × 475 visual viewport and the editor suite used 320 × 475. The panel sweep used touch at both widths and the same reduced height. Provider mock tests capture actual host requests. [Default navigation](audit-evidence-extension-ux/navigation-default.json) · [Companion navigation](audit-evidence-extension-ux/navigation-companion.json) · [Editor and keyboard cases](audit-evidence-extension-ux/editors.json) · [Panel sweep](audit-evidence-extension-ux/panel-sweep.txt)

One independent reviewer received only task goals. The reviewer completed the next-turn, correction, library-export, and preset identification tasks and predicted the cost of an older-reply action. The first pass exposed offscreen direction entry and confirmation, ambiguous saved-button wording, and missing reply context for corrections. The touch retest confirmed those fixes and identified a stale library scroll position. The follow-up regression exercises that position and unsaved editor recovery. [Cold review and retest](audit-evidence-extension-ux/cold-touch-review.md)

The preset regression found that restoring wording could collapse the affected block when its summary changed. Stable disclosure keys keep the block open through restore, Undo and applying a variation. The log retest found feedback disappearing during a redraw. The final inline confirmation mounts with the controls, retains the reviewed count across redraws and checks it again before clearing. [Variation trace](audit-evidence-extension-ux/prompt-variations.json) · [Editor evidence](audit-evidence-extension-ux/editors.json)

## Warmed interaction cost

Measured input handler to rendered layout in Chromium at 390 × 475 on the same host and library. The library held 184 available actions including 160 authored fixtures. Each value below is the median of 14 samples from two paired runs, each with its own warm-up operation.

| Action | Baseline | Revised |
| --- | ---: | ---: |
| Open and dismiss Quick actions | 29.2 ms | 19.0 ms |
| Switch from Reply Display to Settings | 67.7 ms | 45.1 ms |
| Filter the action library | 32.9 ms | 33.1 ms |
| Search for a tool | New action | 9.2 ms |

An initial pass across different accumulated host fixtures measured 49.2 ms for filtering. The controlled pairs measured 31.1 → 36.3 ms and 34.0 → 30.3 ms with the same library, each inside the 20% threshold. All four paired runs made zero model calls.
